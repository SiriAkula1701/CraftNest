\# CraftNest – Handmade Crafts E-Commerce Website



\## About the Project

CraftNest is a handmade crafts e-commerce website developed using PHP and MySQL. It provides a platform for customers to explore and purchase handmade products.



\## Features



\### User Features

\- User registration and login

\- Browse products by category

\- View product details

\- Add products to cart

\- Add products to wishlist

\- Place and view orders

\- Cancel and return orders



\### Admin Features

\- Admin login

\- Add new products

\- Edit product details

\- Manage product listings



\## Technologies Used

\- Frontend: HTML, CSS

\- Backend: PHP

\- Database: MySQL

\- Development Environment: XAMPP



\## Installation and Setup



1\. Install XAMPP.

2\. Clone or download this repository.

3\. Place the project folder inside the `htdocs` directory.

4\. Start Apache and MySQL from the XAMPP Control Panel.

5\. Open phpMyAdmin and create a database named `craft\_nest`.

6\. Import the provided SQL file into the database.

7\. Configure the database connection in `includes/db.php`.

8\. Open the project in your browser:



&#x20;  `http://localhost/CraftNest/`
